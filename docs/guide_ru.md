# StarMade Block Editor — Руководство пользователя

Это руководство объясняет, как пользоваться StarMade Block Editor: запуск, настройка, выбор блоков, редактирование, текстуры, иконки и сохранение.

---

## 1. Назначение приложения

StarMade Block Editor — локальное веб-приложение для визуального редактирования определений блоков StarMade.

Оно состоит из двух частей:

- **сервер**, который читает и записывает файлы StarMade;
- **браузерный интерфейс** со списком блоков, 3D-просмотром, выбором текстур/иконок и редактором свойств.

В production-режиме приложение доступно по адресу:

```text
http://localhost:3847
```

Редактор читает vanilla-данные StarMade, но сохраняет изменения как custom overrides. Это помогает не изменять исходные файлы игры напрямую.

---

## 2. Запуск приложения

### Windows

```bat
start.bat
```

### Linux / macOS / WSL

```bash
./start.sh
```

Скрипт запуска проверяет Node.js/npm, устанавливает зависимости при необходимости, собирает приложение, если нет `dist`, запускает сервер и открывает браузер.

Принудительная пересборка:

```bash
./start.sh --rebuild
```

```bat
start.bat --rebuild
```

---

## 3. Первая настройка

При первом запуске укажите папку установки StarMade.

Примеры:

```text
D:\Jeux\Steam\steamapps\common\StarMade\
```

```text
/mnt/d/Jeux/Steam/steamapps/common/StarMade/
```

Сервер проверяет папку, в частности наличие:

```text
data/config/BlockConfig.xml
```

Если сервер запущен в WSL, Windows-пути автоматически преобразуются в `/mnt/<drive>/...`.

Локальная конфигурация хранится в:

```text
SMToolConfig.json
```

---

## 4. Основной интерфейс

Интерфейс разделён на три колонки:

```text
Список | 3D-просмотр | Свойства
```

### Список блоков

В левой панели можно:

- искать по имени, XML-типу или ID;
- показывать/скрывать vanilla-блоки;
- показывать/скрывать custom-блоки;
- показывать/скрывать deprecated-блоки;
- выбрать блок для редактирования.

### 3D-просмотр

Просмотр показывает выбранный блок с геометрией и atlas mapping в стиле StarMade.

Можно:

- вращать, приближать и перемещать камеру;
- менять ориентацию блока;
- переключать active/inactive preview;
- предварительно смотреть источники света;
- выбирать грань для редактирования текстуры.

### Панель свойств

Панель редактирует черновик выбранного блока:

- идентичность, имя, описание и иконка;
- hitpoints, масса, объём, цена и броня;
- форма, ориентация, slab и варианты;
- параметры рендера и текстур;
- gameplay/logic/shop/deprecated flags;
- цвет и интенсивность света;
- расширенные свойства BlockConfig.

---

## 5. Процесс редактирования

1. Выберите блок в списке.
2. Блок появится в 3D-просмотре.
3. Панель свойств создаст редактируемый черновик.
4. Измените поля, текстуры, иконку или расширенные свойства.
5. Сохраните.
6. Сервер запишет custom-данные и перезагрузит блок.

Важно: редактирование vanilla-блока не меняет vanilla-файл напрямую. При сохранении создаётся custom override.

---

## 6. Сохранение и custom-блоки

При сохранении:

- vanilla-блок становится custom override;
- существующий custom-блок обновляется;
- неизвестные XML-свойства по возможности сохраняются;
- интерфейс помечает блок как custom.

Такой подход защищает исходные данные игры.

---

## 7. Создание нового блока

Нажмите **New block** в верхней панели.

Приложение создаст custom-блок со значениями по умолчанию, выберет его и откроет в редакторе.

---

## 8. Редактирование текстур

### Выбор граней

Под 3D-просмотром находится выбор граней. Он зависит от `IndividualSides`:

- **1 сторона:** все грани используют одну текстуру;
- **3 стороны:** группы front/back, top/bottom, left/right;
- **6 сторон:** каждая грань имеет свою текстуру.

Нажмите на грань, чтобы открыть atlas picker.

### Atlas picker

Атлас показывает тайлы StarMade. Клик по тайлу назначает его ID выбранной грани.

| Page | Источник | IDs |
|---|---|---|
| 0 | `t000.png` | `0–255` |
| 1 | `t001.png` | `256–511` |
| 2 | `t002.png` | `512–767` |
| 3 | `t003.png` | `768–1023` |
| 4–6 | зарезервировано | `1024–1791` |
| 7 | `custom.png` | `1792–2047` |

### Менеджер custom atlas

Он позволяет:

- импортировать полный custom atlas;
- заменить один custom tile;
- выбрать diffuse или normal map.

После импорта кэши атласа обновляются.

---

## 9. Редактирование иконок

Откройте icon picker из панели свойств.

Он показывает листы иконок StarMade и записывает числовой ID иконки в черновик блока.

---

## 10. Формы и правила рендера

| BlockStyle | Форма |
|---|---|
| 0 | Cube |
| 1 | Wedge |
| 2 | Corner |
| 3 | Cross |
| 4 | Tetra |
| 5 | Penta |
| 6 | Hepta / fallback cube |

Важные правила:

- Cross-блоки используют alpha из текстуры даже без `Transparency`;
- анимированные текстуры переходят по последовательным тайлам;
- activation textures используют соседний tile по правилам StarMade;
- slabs меняют толщину в preview;
- orientation вращает асимметричные формы.

---

## 11. Просмотр света

Блоки с `LightSource` можно просматривать как активные источники света.

`LightSourceColor` использует формат:

```text
[r, g, b, intensity]
```

Первые три значения — цвет, четвёртое — интенсивность.

---

## 12. Расширенные свойства

BlockConfig содержит специальные поля для ресурсов, рецептов, factories, chambers, controllers, collision, LOD, логики и gameplay.

Расширенный редактор даёт структурированные элементы управления для частых полей и сохраняет неизвестные поля, чтобы не потерять данные.

Если вы не знаете назначение свойства, оставьте его без изменений.

---

## 13. Язык

Переключатель языка в верхней панели меняет подписи и подсказки интерфейса. Сохранённые данные StarMade не изменяются.

Доступные языки: английский, французский, немецкий, испанский, русский и японский.

---

## 14. Рекомендуемый безопасный процесс

1. Сделайте резервную копию custom-файлов StarMade.
2. Запустите редактор.
3. Редактируйте один блок за раз.
4. Сохраните.
5. Перезагрузите приложение и проверьте значения.
6. Проверьте изменения в StarMade, если они влияют на gameplay.

---

## 15. Решение проблем

### Папка StarMade недействительна

Проверьте, что путь содержит или ведёт к:

```text
data/config/BlockConfig.xml
```

### Текстуры не обновляются

Откройте атлас заново, используйте кнопку reload textures или перезапустите приложение.

### Браузер не открылся

Откройте вручную:

```text
http://localhost:3847
```

### Ошибка сборки

```bash
npm install
npm run build
```

Затем запустите с `--rebuild`.
